Frequently Asked Questions

Common questions about the API integration, available services, and testing environment.

Q

Do you offer any REST/SOAP API in order to provide a communication channel to the Rayna Tours platform?

A

We provide the REST API. Request and response are in JSON format (JavaScript Object Notation).

Q

What kinds of services are available through this API?

A

API services include a vast pool of tours from UAE, Singapore, Malaysia, Thailand, and Hong Kong — covering attractions and activities to help you distribute products globally.

Q

Is there a way to discover available ticket options? For example adult ticket day pass, child day pass, weekly pass, etc.

A

We provide tour time slots & ticket availability through the APIs so you can select the timeslot, transfer option, and tickets for adult, child, and infant.

Q

Is there a sandbox environment available where we can perform some tests?

A

Yes, we provide a Sandbox environment with test booking details.
