City API

Fetch the list of cities for a given country. Pass the countryId obtained from the /api/Tour/countries endpoint.

Request URL

POST /api/Tour/cities

This URL is for fetching City data.

JSON Request Format

JSON — Request 
{
  "CountryId": 1   // CountryId from /api/Tour/countries
}

Request Parameters

TagDescriptionOptionality
CountryId Tour's country id. Obtained from /api/Tour/countries. Mandatory

JSON Response Format

JSON — Response 
{
  "statuscode": 200,
  "error":      "Error description",
  "url":        "Url",
  "count":      25,
  "result": [
    {
      "cityId":   101,
      "cityName": "City Name"
    }
  ]
}
