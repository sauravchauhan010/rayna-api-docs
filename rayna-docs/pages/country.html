Country API

Fetch the list of all available countries supported by the system.

Request URL

POST /api/Tour/countries

This URL is for fetching Country data.

JSON Response Format

JSON — Response 
{
  "statuscode": 200,
  "error":      "Error description",
  "url":        "url",
  "count":      10,
  "result": [
    {
      "countryId":   1,
      "countryName": "Country Name"
    }
  ]
}
