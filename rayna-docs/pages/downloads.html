Image Path

Image paths returned by the API come in two forms — full URLs and partial paths. You must handle both cases when rendering images.

FULL URL starts with http

Use the URL as-is. No modification needed.

PARTIAL PATH starts with /

Prepend the CDN base URL and append _L.jpg

CDN Base URL

CDN 
https://d2cazmkfw8kdtj.cloudfront.net

Construction Logic

API returns image path
IF path starts with "http" → use directly
e.g. https://d2cazmkfw8kdtj.cloudfront.net/Tour-Images/.../filename.jpg
IF path does NOT start with "http" → construct URL
// Partial path from API:
/Tour-Images/Final/Dubai-Dolphinarium-65/1725257059039

// Result:
https://d2cazmkfw8kdtj.cloudfront.net/Tour-Images/Final/Dubai-Dolphinarium-65/1725257059039_L.jpg

Code Example

JavaScript 
const CDN_BASE = 'https://d2cazmkfw8kdtj.cloudfront.net';

function getImageUrl(imagePath) {
  if (!imagePath) return null;

  // Full URL — use as-is
  if (imagePath.startsWith('http')) {
    return imagePath;
  }

  // Partial path — prepend CDN + append _L.jpg
  return CDN_BASE + imagePath + '_L.jpg';
}

Date Format

The following date formats are accepted in the request payload:

Accepted Formats 
// Supported date formats for payload
1) MM/dd/yyyy    // e.g. 12/31/2024
2) MM-dd-yyyy    // e.g. 12-31-2024
3) yyyy-MM-dd    // e.g. 2024-12-31
4) yyyy/MM/dd    // e.g. 2024/12/31
5) MM.dd.yyyy    // e.g. 12.31.2024
